# CAOstack

Goalpost Code load path. Not a solvys-skills mirror.

```bash
bash caostack/install.sh
```

That vendors MIT pstack from `github.com/cursor/plugins` into `vendor/pstack` (gitignored) and links `.agents/skills/caostack` plus `poteto-mode`.

`lock.json` lists the rest (ponytail, shadcn-cssinjs, clipth, impeccable, cursor-team-kit). Goalpost Code installs those as plugins. This git tree does not vendor paid zips or internal cabinets.
