# Design skill banks

This template understands design as **banks**, not one frozen canon.

| Bank | When | Source |
| --- | --- | --- |
| shadcn-cssinjs | Align UI while building | https://github.com/shadcn-labs/shadcn-cssinjs |
| shadcndashboard | Paid dashboard kits via solvys-build-kit pointer | Commercial zip. Not in this git tree |
| impeccable | Polish after the feature exists | impeccable skill |
| product | Repo Design.md / tokens | The cloned company repo |

Add a bank by dropping a markdown file in this folder that names the registry, license, and when to load it. Do not vendor BeUI or ChatGPT Site as the default religion.
